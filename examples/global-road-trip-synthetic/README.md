# Synthetic global road-trip example

This folder demonstrates plan-versus-actual records and family rules without publishing a real family's itinerary.

All people, dates, place names, routes, costs, and identifiers are synthetic. The example preserves only reusable decision patterns:

- full-meal and light-meal alternatives;
- breakfast distance comparisons;
- hotel laundry and parking action cards;
- venue closure and weather replanning;
- separation of a one-time feedback case from a confirmed family rule;
- global source roles and provider fallback status.

This is demonstration data, not a current destination recommendation. Recheck every time-sensitive fact before using a similar plan.
