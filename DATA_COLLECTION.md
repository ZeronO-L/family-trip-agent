# Data Collection

Family Trip Agent version `0.1` does not collect or transmit project telemetry.

Specifically, the repository includes no:

- analytics SDK;
- tracking pixel;
- hosted database;
- background uploader;
- user account or advertising identifier;
- automatic sharing of trip files with maintainers.

The plugin can ask Codex to research current travel information. Any web access, model processing, or connector use is performed through the user's own environment and is subject to the policies of those services.

If a future contribution proposes data collection, it must be opt-in, documented before release, minimized to a stated purpose, and reviewed as a separate architectural decision.
